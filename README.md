# Lev (LEV) — страница за създаване на токена

Статична страница за браузъра на Phantom, с която собственикът сам създава токена **Lev (LEV)** в Solana:
фиксирани 21 000 000 LEV, 6 десетични знака, отнети права за сечене и замразяване, непроменими метаданни.
Всяка транзакция се подписва в Phantom — ключовете не напускат портфейла.

Отвори в Phantom: https://lev-coin.github.io/

Файлове: `index.html`, `app.js` (сглобен код), `lev_256.png`, `lev_64.png`. Изходният код е в отделна папка `lev_launch/src`.
